## Summary

- **New `ProducerConsumerWarpSpecialized` pass** for sm90+ TMA pipelines: splits pipelined loops into producer (128 threads, TMA loads) and consumer (compute) warp groups with back-pressure mbarrier synchronization. Supports `num_stages >= 1`.
- **New `T.tma_copy()` API**: fire-and-forge
