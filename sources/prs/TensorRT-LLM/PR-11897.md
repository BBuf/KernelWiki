## Summary

Add fused FC1 GEMM + SwiGLU activation kernels for shared experts in DeepSeek-V3 with NVFP4 quantization, producing both BF16 and FP4 output variants.

Perf result on GB200 1k/1k 1ctx + 2gen DEP8 bs512 DeepSeek-FP4 tps/user:
before fusion : 24.37 tok/s
after fusion : 25.24 tok/s
~3.5% perf impr
