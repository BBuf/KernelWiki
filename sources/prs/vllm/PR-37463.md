## Purpose

Adds an MXFP4 W4A4 MoE kernel path using CUTLASS on SM100f Blackwell. This enables W4A4 inference for MXFP4-quantized MoE models using the `mx_float4_t` type with E8M0 block-32 scales, distinct from the existing NVFP4 path which uses `nv_float4_t` with E4M3 block-16 scales and a global s
